# ⭐ Star Catcher

**Star Catcher** is a free online gaming website where you can play fun browser games instantly.

No downloads. No sign-up. Just play!

## 🎮 What is this?

Star Catcher is a simple, mobile-friendly game website built with HTML, CSS, and JavaScript.  
It currently includes **Star Catcher**, a fast arcade game where you move a basket to catch falling stars while avoiding bombs.

## 🕹️ How to play

- Move the basket using your mouse or by dragging your finger on the screen.
- Catch ⭐ stars to increase your score.
- Avoid 💣 bombs, or you will lose a life.
- You start with 3 lives.
- When you lose all lives, the game ends.

## 🚀 Run the website

1. Download or copy the project files.
2. Open `index.html` in any web browser.
3. Start playing.

No installation is required.

## 🌐 Publish it free

You can host Star Catcher for free using:

- GitHub Pages
- Netlify
- Cloudflare Pages
- Vercel

For GitHub Pages:

1. Create a new public GitHub repository.
2. Upload `index.html` and `README.md`.
3. Go to **Settings → Pages**.
4. Select your main branch and `/ (root)`.
5. Save, then open your live website link.
